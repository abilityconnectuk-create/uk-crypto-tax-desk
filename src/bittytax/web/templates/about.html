About

This is a local desk for BittyTax. It listens on this computer and reads a data directory there. Another device reaches it only through Tailscale on your private tailnet.

What the desk does not do

It does not contact a price service. A row needs a value in the local currency, the value the conversion tool kept from the export. It does not edit the calculator's tax rules. If a figure looks surprising, the command-line report on the derived records file is the same calculation.

A browser on this computer, at 127.0.0.1, does not ask for a password. A browser that arrives through Tailscale Serve does. Do not publish the desk on the public internet, and do not turn on Tailscale Funnel.
