Where to download

Import the CSV itself. Do not open it in a spreadsheet and save it again. A zip from the exchange should be unpacked first.

Coinbase

On the Coinbase website, open your profile, then Settings, then Accounts, then Statements. Generate a custom statement for all assets and all transaction types, and choose CSV. Coinbase emails the file. Any filename is fine when the header row starts with ID, Timestamp, Transaction Type.

KuCoin spot trades

On the KuCoin website, open Orders, then Export Data. Choose Spot Orders, then Filled Orders, and CSV. Leave order splitting off, so the same fill is not imported twice. The file is named like Spot Orders_Filled Orders. One export covers at most one year.

KuCoin deposits and withdrawals

In the same Export Data screen, choose Deposit/Withdrawal History, then Deposit History and Withdrawal Record. Import each CSV on its own. The files are named like Deposit_Withdrawal History_Deposit History and Deposit_Withdrawal History_Withdrawal Record. Only a row whose status is SUCCESS is mapped. Any other status is skipped.

Revolut X

In the Revolut app, open Crypto, then More, then Documents, then Statement. Choose Excel. The download is a CSV. Choose All time. Revolut X trades are included in that statement, so there is no separate Revolut X file. The header row is Symbol, Type, Quantity, Price, Value, Fees, Date.
